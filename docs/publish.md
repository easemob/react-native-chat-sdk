# 发版流程

## 需求阶段

1. 根据需求说明（jira 任务、HLD 文档链接等）分析关键点，技术风险，可能需要的依赖（例如：后台配置等）
2. 任务可行性拆解

## 开发阶段

1. 接口定义
2. 接口文档说明
3. 平台差异问题
4. 可测试性：准备测试数据。例如：账号、权限开通、后台配置等
5. 测试和验证

## 发布阶段

### 发布国内版本

1. 本地打包、测试
2. 创建测试任务，测试人员测试
3. 发布 npm 包，发布后再次验证, 创建 tag
4. 更新 官网 日志
5. 更新 官网 api 文档
6. 更新 官网 集成 文档 （可选）
7. 更新 示例 项目
8. 更新 jira 版本关系映射

### 发布海外版本

和本地发布相比，多了一个产品审查，需要创建发布任务请求，通过邮件进行申请审核。
